# Results

Stages 04 and 05 write to `table_i/` by default (or to `--output-dir` /
`--results-dir`). Independent Qwen runs write to `independent_table_i/`.
Stage 06 writes the acoustic figures to `acoustic_figures/`.

Included for reference:

- `reproduced_table_i/`: Table I reproduced from raw audio, compared cell by
  cell with the paper.
- `acoustic_figures/`: Figs. 1 and 4 (CODA, Qwen decisions).
